01 · CURRENT

Find what is true now.

Lacuna resolves the standing claim and keeps the quote, source and observation time attached. The model receives an answer it can inspect, not a detached summary.

02 · HISTORY

Keep the old fact without letting it win.

Supersession is explicit. A correction changes the current answer while the earlier claim stays available for audits, timelines and handoffs.

03 · CONFLICT

Refuse to invent consensus.

The billing-gate record names two runbook owners and neither source resolves the other. Lacuna preserves both claims and returns no answer.

04 · GRAPH + TABLE

Move through the field. Verify in rows.

HydraDB holds the temporal evidence graph. The overview is for navigation; the proof path shows exact edges; the table makes every visible record readable.

05 · CLIENTS

Connect the tools you already use.

Claude, ChatGPT read and fetch, Codex, local runtimes and custom clients can address the same workspace through MCP, the CLI or the HTTP API.

06 · AGENTS

Turn memory into governed work.

Researcher and Reviewer presets start with a bounded Context Pack. Runs retain their lifecycle, tools, artifacts and final state; schedules retain their next eligible time.

07 · VOICE

Talk to the same evidence path.

The governed voice route exposes listening, transcription, thinking, speaking, interruption and failure as explicit states. When speech is unavailable, the typed path remains.

08 · BUILD

Inspect the contract, then integrate.

The product exposes its SDK and API contract, MCP transports, CLI commands, health checks, HydraDB boundary and measured evaluation artifacts inside the workspace.
