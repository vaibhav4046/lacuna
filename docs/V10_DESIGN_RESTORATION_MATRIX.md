# V10 approved-design restoration matrix

Source of truth: `design/reference/Lacuna Product.dc.html`, the React port at
`132d734`, the Memory Gravity Field at `e6bca46`, and the user-approved hero
evidence in `artifacts/screens/v5/landing-hero-1440.png`.

The rejected V8 composition wrapped the signature field in a generic aperture,
replaced semantic scroll progress with repeated card swaps, used large amber
glows, and removed most particle morph states. V10 restores the original visual
language while compressing excessive dwell into thirteen coherent chapters.

## Fixed visual contract

- Pure black ground, white and gray editorial type.
- Space Grotesk for display and body; JetBrains Mono for evidence and utility.
- One persistent Canvas 2D particle system and one semantic state machine.
- Violet is interaction. Amber is a rare evidence or warning spark.
- No glass panel around the hero, no header pill, no generic story card shell.
- Real product artifacts stay readable and enter the same spatial narrative.
- Reduced motion resolves every scene to a complete static composition.

## Motion acceptance

- Each semantic beat has a unique `data-scene` and continuous 0 to 1 progress.
- Artifacts establish, exit or dissolve before the next artifact forms.
- First downward visit receives the full morph. Revisit uses the resolved state.
- No empty black desert, sudden teleport or repeated generic panel.
- Text shields cover text, never an entire half-page visual.
- Pointer gravity stays weak and semantic hotspots remain keyboard-peerable.
- Header identity remains visible while the hero mark can transform.
