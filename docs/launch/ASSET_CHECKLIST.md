# Launch asset checklist

## Required proof assets

- [ ] **15-second hook:** one memory failure and Lacuna's different outcome.
- [ ] **45–60-second proof demo:** input, result, evidence, timeline/conflict and repository URL.
- [ ] **Architecture image:** sources → evidence graph → temporal resolver → web/CLI/MCP.
- [ ] **Repository social preview:** `web/public/social.png` uploaded in GitHub Settings.
- [ ] **One clean screenshot:** readable at LinkedIn mobile width without tiny labels.
- [ ] **One failure/fix asset:** before and after, with the exact issue or commit linked.

## Recording rules

- Show the product within the first two seconds.
- Use real product motion, not a frame-by-frame concept render.
- Keep browser zoom high enough for mobile viewing.
- Remove tokens, cookies, personal data, internal URLs and private workspace content.
- Use captions; many viewers watch muted.
- End on one action only: try the demo or inspect the repository.

## Claim check before export

- [ ] Every number matches current repository evidence.
- [ ] No winner language appears before results are announced.
- [ ] The generated 64-question check is not called official LongMemEval.
- [ ] Named client support matches completed external verification.
- [ ] Public and authenticated workspace boundaries are not conflated.
