## Services Lacuna talks to

### HydraDB

- **Upstream:** https://github.com/hydra-db/hydradb
- **License:** AGPL-3.0
- **Pinned at:** `02a40025d2d57e97ab2754c8256219cdbfeab379`
- **How it is used:** run as a separate process. Lacuna speaks to it over its
  documented HTTP query API.
- **What is NOT done:** no HydraDB source is copied, vendored, linked or
  otherwise incorporated into this repository. There is no derivative work of
  HydraDB here.

Why that distinction is stated so plainly: AGPL-3.0's obligations attach to
derivative works and to modified versions offered over a network. An independent
client that speaks a documented wire protocol to an unmodified upstream server is
neither. Keeping the boundary at the network API is a deliberate design decision,
recorded as [D-003](DECISIONS.md).

If HydraDB itself is ever modified for this project, that fork gets published
under AGPL-3.0 as the license requires. As of 2026-08-12 it has not been modified.

HydraDB's own third-party dependencies, including `libcypher-parser` and
SuiteSparse GraphBLAS, are HydraDB's to declare and are installed as system
packages rather than bundled here.
