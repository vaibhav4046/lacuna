## Features

- Keep **Issues** enabled.
- Enable **Discussions** only when there is capacity to answer questions.
- Enable **Private vulnerability reporting**.
- Prefer squash merge for focused contribution history.
- Add branch protection after the current CI path is stable: required checks,
  no force pushes and at least one review for external contributors.

## Profile conversion

Pin Lacuna first on the creator profile. Use the same real name, photo and one-line
positioning on GitHub, LinkedIn and X so discovery transfers between platforms.
