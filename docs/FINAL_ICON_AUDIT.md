# V10 icon and mark boundary

Reviewed 2026-08-21. The canonical Lacuna mark is the white spiral with the
amber `#FFB829` head on black in `web/public/mark-256.png` and
`web/public/favicon.svg`. A purple logo, violet halo or the older orange-head
reference export is not an approved Lacuna mark.

| Mark | State | Use |
| --- | --- | --- |
| Lacuna | project-owned | canonical pixel mark used in product and media |
| HydraDB | credited | third-party attribution is in `THIRD_PARTY.md` |
| Google G | approved standard-colour asset | authentication button only |
| Claude | credited vendor asset | external-client explanation only |
| OpenAI / ChatGPT | credited vendor asset | external-client explanation only |
| generic UI icons | project CSS/SVG | functional controls, labelled for assistive technology |

No vendor mark is used to imply sponsorship. Product copy distinguishes a real
connection from a protocol example. Graph controls use text symbols with
explicit accessible names; decorative particles and the landing field are
hidden from assistive technology.

The prior icon audit remains the detailed provenance history. Thumbnail rules
and the submission asset list are in `V10_THUMBNAIL_BRIEF.md`; this file does
not replace `THIRD_PARTY.md`.
